# Uber Ride Demand Prediction System using Machine Learning and Flask

## 1. Project Overview

The main objective of this project is to predict the number of weekly Uber riders based on various influencing factors such as Price per week, Population, Monthly income, and Average parking cost per month.

This project uses Machine Learning to analyze historical data patterns and predict the expected number of Uber riders in a particular area or city. The system helps understand how different real-world factors affect transportation demand.

The prediction system is developed using Python, Flask, HTML, CSS, and Machine Learning (Linear Regression).

---

## 2. Problem Statement

Transportation companies like Uber need to estimate future ride demand to improve their services.

Without prediction systems, companies may face problems such as:

- Shortage of drivers in high-demand areas
- Too many drivers in low-demand areas
- Poor pricing strategies
- Reduced customer satisfaction

This project solves the problem by predicting the number of weekly Uber riders based on multiple influencing factors.

---

## 3. Objective of the Project

The objective of this project is:

To build a machine learning-based system that predicts the number of Uber riders per week using different factors such as price, population, monthly income, and parking cost.

This system helps in demand forecasting and business planning.

---

## 4. Technology Stack Used

### Frontend
The frontend is developed using:

- HTML
- CSS

Purpose:
The frontend provides a user-friendly interface where users can enter input values for prediction.

### Backend
The backend is developed using:

- Python

Purpose:

Workflow:

User Input → Flask Backend → Machine Learning Model → Prediction Result

### Machine Learning Algorithm
The algorithm used in this project is:

Linear Regression

Purpose:

## 5. Dataset Explanation

The dataset used in this project contains Uber-related information.

### Dataset Format

Priceperweek, Population, Monthlyincome, Averageparkingpermonth, Numberofweeklyriders

The dataset contains 5 columns.

---

### 5.1 Priceperweek

Meaning:

This column represents the average amount spent on Uber rides per week.

Example:

Priceperweek = 1200

Meaning:

A person spends approximately ₹1200 per week on Uber rides.

Importance:

Price directly affects ride demand.

Generally:

- Higher price → Lower riders
- Lower price → Higher riders

Because expensive ride costs reduce customer usage.

---

### 5.2 Population

Meaning:

This column represents the population of the city or area.

Example:

Population = 5000000

Meaning:

The city has approximately 50 lakh people.

Importance:

Population strongly affects Uber demand.

Generally:

Higher population → Higher ride demand

Because more people create more transportation demand.

---

### 5.3 Monthlyincome

Meaning:

This column represents the average monthly income of people in that area.

Example:

Monthlyincome = 45000

Meaning:

The average monthly salary of people is ₹45,000.

Importance:

Income affects Uber usage.

Generally:

Higher income → Higher Uber usage

Because people with better income can afford ride-sharing services more frequently.

---

### 5.4 Averageparkingpermonth

Meaning:

This column represents the average monthly parking cost.

Example:

Averageparkingpermonth = 3000

Meaning:

The average parking expense per month is ₹3000.

Importance:

Parking cost influences transportation decisions.

Generally:

Higher parking cost → More Uber usage

Because people may prefer Uber instead of maintaining personal vehicles when parking becomes expensive.

---

### 5.5 Numberofweeklyriders

Meaning:

This column represents the total number of Uber riders per week.

This is the target variable (output) in the machine learning model.

Example:

Numberofweeklyriders = 250000

Meaning:

Approximately 2.5 lakh people use Uber weekly.

The model predicts this value.

---

## 6. Why Linear Regression?

Linear Regression is used because:

1. The output is numerical.

Example:

250000 riders

2. It identifies relationships between variables.

Example:

- Price increases → Riders decrease
- Population increases → Riders increase

3. It is simple, efficient, and suitable for prediction problems.

---

## 7. Project Workflow

### Step 1: Data Collection

The Uber dataset is collected and stored in CSV format.

The dataset contains:

- Price per week
- Population
- Monthly income
- Parking cost
- Weekly riders

---

### Step 2: Data Preprocessing

Before training the model:

- Missing values are checked
- Unnecessary data is removed
- Features are selected

This improves prediction quality.

---

### Step 3: Model Training

The dataset is trained using the Linear Regression algorithm.

The model learns relationships between features.

Example:

High population + affordable price = More riders

---

### Step 4: Model Saving

After training, the machine learning model is saved using Python Pickle.

Example:

model.pkl

Purpose:

The saved model can be reused without retraining every time.

---

### Step 5: Flask Integration

Flask connects the frontend with the trained machine learning model.

Workflow:

User enters values → Flask sends input → Model predicts → Result displayed

---

### Step 6: Prediction

The trained model predicts the expected number of weekly Uber riders.

Example Input:

- Price per week = ₹1200
- Population = 50,00,000
- Monthly Income = ₹45,000
- Parking cost = ₹3000

Example Output:

Predicted Weekly Riders = 2,80,000

Meaning:

Approximately 2.8 lakh people may use Uber weekly.
